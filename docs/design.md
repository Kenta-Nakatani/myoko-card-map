# デザインと編集方針

目的: QRから訪れた人が、カードの風景と場所を写真・地図で確かめられるサイト。

参考: https://kiseki-lab.github.io/2026-memory-map-report/
写真を大きく見せること、文字と余白の階層、説明と操作が対応する構造を参考にする。
活動報告のカレンダーや本文、写真そのものは転用しない。

## 構成

1. 風景写真と地図への入口
2. 妙高の四季（写真の切り替え）
3. 地図とカードの地点情報
4. カードの拡大と使い方
5. 三段階の楽しみ方

## 表現

紙に近い背景、深い緑の文字、細い罫線。大きな写真と余白を軸にする。
緑は主要な操作、薄い緑は選択中、茶色は市境や地図の選択地点に使う。
本文は16px基準。見出し、説明、補足、ボタンを別の大きさにする。
役割のない英語ラベル、発光、過剰な影、装飾だけの図形は加えない。
実在の観光地点や撮影場所を推測して追加しない。

## 操作

スマホでは地図と地点情報を縦に置く。ヘッダーから地図へ移動できる。
地図のパンは指2本、PCのホイールズームはCtrl併用にしてページのスクロールを妨げない。
カード拡大はdialogでフォーカスを閉じ込め、Escで閉じ、元の操作へ戻す。
動きを減らす設定では滑らかなスクロールや地図の飛行アニメーションを抑制する。

## 素材と未確定事項

素材は元サイトから継承。四季の写真の具体的な撮影場所・撮影者は未確認。
カード01の地図は、ユーザー提供のイモリ池の座標を使用する。
