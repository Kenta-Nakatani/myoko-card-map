# カードとずかんのローカル試作（2026-10-07）

参考: https://hana-scan.netlify.app/

生成り・深緑・黄色、明朝の見出し、余白を参考に、カード・地図・ずかんの3画面を作成。
図鑑は妙高高原・まちなかぷらす・かんずり・和光の4件。追加3件の外観と店内・商品の写真はユーザー提供素材を使用。カメラ認識は実装していません。地図はユーザー提供のイモリ池の座標を使用し、追加3件の座標は未設定です。
カードの保存は明示ボタンで行い、localStorageにカードIDを記録します。ログインや端末間同期はありません。
以前のQRリンクの #map と、#book への直接アクセスに対応しています。

確認: 静的ビルド成功、390px幅で横はみ出しなし、画像読み込み、保存と再読み込み後の復元、地図の選択、カード拡大、使い方表示、Escで閉じる動作。
プレビュー: http://localhost:3001/myoko-card-map/
GitHubと公開サイトは更新していません。
追加確認: 4件の一覧表示、かんずりの保存と再読み込み後の復元、既存の妙高高原の保存記録の保持、3件の詳細と写真、390px幅で横はみ出しなし。
